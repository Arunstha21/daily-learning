AI-001 · +3 days

What “AI” usually means in everyday tools

Software that has learned patterns from large amounts of data and uses those patterns to produce predictions, suggestions, content, or decisions when it receives new input.
Example: phone camera — input is a low-light photo; output is a brighter, clearer image produced by patterns learned from many previous images. (Other valid: autocomplete, traffic prediction, chatbot reply.)

BE-001 · +1 day (due 29 July, now overdue)

What opportunity cost is and how it helps everyday decisions

The value of the next-best alternative you give up when you choose one option. It is not only money; it includes time, attention, and other resources.
Example: spending an evening watching videos instead of practising a skill — the opportunity cost is the progress or practice you did not get. (Any clear “chosen option vs next-best forgone alternative” is valid.)

PC-001 · +3 days (due 29 July)

How to explain an idea clearly using Context, Point, and Example

Context (set the situation), Point (state the main idea clearly), Example (give one concrete illustration).
Context orients the listener so they know why the idea matters; the point then lands clearly; the example makes it concrete. Without the structure, details can feel floating and hard to remember.

ITF-001 · still overdue intervals

How DNS helps your browser find a website

DNS translates the human-readable domain name into the numerical IP address the computers on the network actually use to reach the server.
You can keep the same easy-to-remember name even if the server’s IP address changes (for example when a site moves to a new host). DNS is the lookup that keeps the two linked.
